Not synced yet. ⇅ WH24 Sync
Syncing reads WorkHub24 as you, from your own browser. Nothing stores your WorkHub password.
  1. Drag the orange WH24 Sync button onto Chrome's bookmarks bar. You only do this once.
  2. Open WorkHub24 and sign in. Any page there will do.
  3. Click the WH24 Sync bookmark. It opens this page, reads every ticket since the date above and any new GIN PDFs, and passes them across.
  4. Check the changes it lists here and press Publish.
Moved the date? Drag the button to the bar again. Only GINs this page has not read before are downloaded, so a sync after the first is quick.
